\begin{abstract}
A long-running LLM agent cannot keep every turn of a conversation in its
context window, so a memory layer must decide what to keep, compress, forget
and recall. Tiered memory systems make these decisions, but the policy itself is
rarely measured in isolation. We present MemGate, an evaluation
harness that places memory policies on a common accuracy-per-token frontier,
changing one factor per comparison. The usual accounting bounds the assembled
context but not the store, charging a store-everything baseline nothing for
retention. With the store also bounded,
choosing which turns to forget is worth $+9.37$ answer-recall points over
oldest-first eviction at identical storage, fidelity and retrieval (95\% CI
$[+5.45, +14.90]$, clustered by conversation), while compressing an evicted
turn instead of dropping it loses $7.13$ points; the rate--distortion crossover
is not reached up to $182\times$ compression. Charging the budget for the
embedding index reverses the ranking below about 40\,KiB. An LLM-judged
salience scorer loses to a regular-expression heuristic by $5.87$ points,
whereas a logistic scorer over shallow features and a sentence embedding,
trained on LoCoMo and REALTALK, beats the heuristic by $+14.55$ points on
held-out conversations. It also beats MemGPT-style and Mem0-style memory
rebuilt in the same harness at every budget tested, and on million-token chats
typed into the application it keeps the answer for 51.9\% of questions against
19.2\% for retrieval. Through a fixed reader, $+6.0$ points of the selection
advantage become correct answers. We release the policy as an offline chat
application, and report three measurement errors found by invariants.
\end{abstract}
